# Session Clock vs Visual Rendering

| Concern | Hidden / Reduced FPS |
|---------|----------------------|
| RAYD8 session clock | Continues per existing rules |
| Visual rendering | Paused / throttled |
| Foreground return | Render from elapsed time |

Adaptive FPS must not lengthen sessions, alter Amrita 50% trigger, pass order, glyph order, or Hamsa protocol timing.
